# HAYAATI WEB TECHNOLOGY — MASTER IMAGE PROMPTS ARCHIVE

This document provides the complete, authoritative specification for every image visual slot on **www.hayaatiweb.site**.

### Generation Standards & Rules
1. **Photorealism Only:** Every prompt is engineered for cinematic realism (high-end architectural photography, medical clinical photography, or film stills).
2. **Prohibited Elements:** Strictly NO logos, NO brand trademarks, NO hand-drawn/cartoon/anime styles, NO CGI orb art, NO text in image, and NO watermarks.
3. **Optimised Delivery:** Format must be `.webp`. All cards are lazy-loaded with proper `sizes` and aspect ratios.
4. **Fallback Mechanism:** Until a file is generated, the site automatically renders a solid dark HUD frame with the card title.
