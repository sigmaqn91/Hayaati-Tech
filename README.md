1. **Hero:** Cinematic vision with live telemetry, canvas data-grid, and decrypt typography.
2. **Future Timeline:** 3 eras (2030, 2035, 2050) with panoramic banners, narrative day-in-the-life stories, and innovation dossiers.
3. **Future Tech Catalogue:** 42 specifications across 7 frontiers (AI, Vehicles, Devices, Home/Workplace, Health, Energy, Deep Space) with interactive filters and theoretical mechanics.
4. **Cities & Places:** 8 photorealistic postcards detailing emerging terrestrial and orbital habitats.
5. **My Projects:** Honest portfolio display (Live, In Progress, Future Ideas) awaiting entries from Aliya Khan.
6. **Advertise / List Your Project:** Validated submission form for pioneering technology ventures, reviewed personally by Aliya Khan.
7. **About — Aliya Khan:** Architect profile and communication matrix.
8. **Contact:** Encrypted message relay transmitting directly to `Hayaati.Technology@gmail.com`.
9. **Built-in Gemini AI Assistant:** Holographic cognitive interface with real-time Speech/Voice link, navigation reasoning, and strict rate-limited cost protection.
10. **24 International Languages:** Automatic browser language detection, manual switcher, and native RTL formatting for Urdu and Arabic.

## 🚀 How to Run Locally on Your Computer

You do not need to be an expert developer. Follow these simple steps:

### Step 1: Install Dependencies
Open your terminal inside the project folder and run:
```bash
npm install
```

### Step 2: Set Environment Variables
Copy `.env.example` to a new file named `.env`:
```bash
cp .env.example .env
```
Open `.env` and fill in your keys:
- `GEMINI_API_KEY`: Get this free from [Google AI Studio](https://aistudio.google.com/).
- `RESEND_API_KEY`: Get this from [Resend](https://resend.com) for sending emails.

### Step 3: Start the Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000`.

## 🎨 How to Generate Real Photorealistic Images

Per Master Specification rules, images are never generated by visitors or at page load. You run this script **ONCE** on your own computer:

### Step 1: Ensure Your API Key is Set
Make sure `GEMINI_API_KEY` is present in your `.env` file.

### Step 2: Run the Generation Script
Run this single command in your terminal:
```bash
npx tsx scripts/generate-images.ts
```

### What the Script Does:
1. It automatically reads every unique prompt in `data/future.ts` and `data/places.ts`.
2. It calls the Google Imagen model (`imagen-3.0-generate-002`).
3. It saves the resulting pictures into `public/images/...` as high-resolution images.
4. If an image already exists on your disk, the script **automatically skips it**, so you will never waste quota or money regenerating an image twice!
5. As soon as the files are in `public/images/`, they will appear instantly on the live website with zero code changes.

*(You can also read all 55 exact prompts in `IMAGE_PROMPTS.md` if you ever want to generate them manually).*

## 🚢 Simple GitHub + Vercel Deployment

### 1. Push Your Code to GitHub
```bash
git add .
git commit -m "feat: complete Hayaati Web Technology platform"
git push origin main
```

### 2. Deploy on Vercel
1. Log in to [vercel.com](https://vercel.com).
2. Click **"Add New"** > **"Project"** and select your GitHub repository.
3. Select **Next.js** framework preset.
4. In **Project Settings > Environment Variables**, add:
   - `GEMINI_API_KEY`: Your Google AI Studio API key.
   - `RESEND_API_KEY`: Your Resend API key for email delivery.
   - `APP_URL`: `https://www.hayaatiweb.site`
   - `NEXT_PUBLIC_APP_URL`: `https://www.hayaatiweb.site`
5. Click **"Deploy"**.

> **Important Note:** Whenever you change any variable starting with `NEXT_PUBLIC_`, you must trigger a **Redeploy** on Vercel for it to update in the browser bundle.

### 3. Connect Domain
- In Vercel Project Settings > Domains, enter `www.hayaatiweb.site` and `hayaatiweb.site`.
- Add the CNAME record in your domain DNS: `cname.vercel-dns.com`.

## 🔐 Environment Variables Summary

| Name | Type | Purpose |
|---|---|---|
| `GEMINI_API_KEY` | **Secret** (Server-only) | Powers the AI assistant and voice reasoning. Never exposed to browser. |
| `RESEND_API_KEY` | **Secret** (Server-only) | Transmits contact & project submission forms. |
| `IMAGE_MODEL` | **Config** | Model used by `scripts/generate-images.ts` (default: `imagen-3.0-generate-002`). |
| `APP_URL` | **Config** | Production server URL (`https://www.hayaatiweb.site`). |
| `NEXT_PUBLIC_APP_URL` | **Config** | Public canonical URL for meta tags. |
